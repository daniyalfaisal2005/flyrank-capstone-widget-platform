# WidgetPulse

FlyRank backend capstone: Embeddable Widget & Lead-Capture Platform.

Status: public repository initialized before implementation. The design, runnable system, tests, and observed evidence will be added in incremental commits. No completed functionality or test results are claimed yet.

Planned stack: Python 3.12, FastAPI, PostgreSQL 16, Docker, and vanilla JavaScript. Local-only contact and newsletter widgets with tenant isolation and durable notifications.
